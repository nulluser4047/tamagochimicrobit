# Tamagotchi Microbit

## Español
Proyecto personal de aprendizaje de Python, MicroPython y robótica con BBC micro:bit. El objetivo es construir una mascota virtual con personalidad, emociones, voz y, más adelante, reconocimiento de voz e inteligencia artificial.

En este repositorio se publicarán únicamente los programas que haya probado y decidido guardar. Los experimentos de la placa se realizan en el [editor oficial de Python](https://python.microbit.org/).

## English
A personal Python, MicroPython and robotics learning project using BBC micro:bit. The goal is to build a virtual pet with personality, emotions and speech, eventually adding voice recognition and AI. Only tested and approved programs will be published here.

## Русский
Личный учебный проект по Python, MicroPython и робототехнике с BBC micro:bit. Цель — создать виртуального питомца с характером, эмоциями и голосом, а затем добавить распознавание речи и искусственный интеллект. Здесь будут публиковаться только проверенные и одобренные программы.
